# 兆西福音博客 - 增强版使用指南

## 📦 新增功能概览

增强版兆西福音博客新增了以下功能：
- 📝 **文章模版管理**：创建和使用预设模版
- 📁 **文件上传管理**：支持图片、视频、音频上传
- 🔗 **链接管理**：添加和管理有用链接
- 🗑️ **删除功能**：支持删除文章、评论等内容

## 🚀 快速开始

### 1. 下载并解压
下载 `兆西福音博客_增强版.zip` 并解压到您的电脑上

### 2. 启动网站
```bash
# 在解压后的文件夹中打开终端
python3 -m http.server 8080
```

### 3. 访问网站
打开浏览器访问：http://localhost:8080

### 4. 测试账号
- **管理员**：pastor@example.com / 123456
- **用户**：sister@example.com / 123456

## 🆕 新功能详细说明

### 📝 模版管理
- **访问方式**：登录后点击导航栏"模版"
- **功能**：
  - 创建新的文章模版
  - 使用模版快速创建文章
  - 分类管理（灵修、讲道、见证、查经）
  - 删除模版（作者或管理员）

### 📁 文件管理
- **访问方式**：登录后点击导航栏"文件"
- **功能**：
  - 上传图片、视频、音频、文档
  - 分类管理文件
  - 预览上传的文件
  - 删除文件（上传者或管理员）

### 🔗 链接管理
- **访问方式**：登录后点击导航栏"链接"
- **功能**：
  - 添加外部链接
  - 分类管理（资源、圣经、赞美等）
  - 标签系统
  - 删除链接（作者或管理员）

### 🗑️ 删除功能
- **文章删除**：文章作者或管理员可以删除自己的文章
- **评论删除**：只有管理员可以删除评论
- **模版删除**：模版创建者或管理员可以删除模版
- **文件删除**：文件上传者或管理员可以删除文件
- **链接删除**：链接添加者或管理员可以删除链接

## 🔐 权限说明

### 普通用户权限
- 使用模版创建文章
- 上传文件
- 添加链接
- 删除自己创建的内容

### 管理员权限
- 普通用户所有权限
- 删除任何用户的文章、评论、模版、文件、链接
- 管理整个网站内容

## ⚠️ 注意事项

### 文件上传
- 支持格式：图片(jpg, png, gif)、视频(mp4, avi)、音频(mp3, wav)、文档(pdf, doc)
- 文件大小限制：建议单个文件不超过50MB
- 上传的文件会在浏览器关闭后丢失（演示版本）

### 安全提醒
- 这是一个演示版本，所有数据存储在浏览器本地
- 生产环境需要添加服务器端验证和安全措施
- 文件上传需要实际的文件存储服务
