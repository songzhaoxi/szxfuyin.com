# 兆西福音博客网站

## 项目简介

这是一个功能完整的福音博客网站，采用现代Web技术构建，提供丰富的功能和优雅的用户体验。

## 功能特性

### 🔐 用户认证系统
- 用户注册和登录
- 身份验证和会话管理
- 用户状态持久化

### 📝 文章管理
- 文章分类浏览（灵修、讲道、见证、查经）
- 分页浏览功能
- 文章详情查看
- 搜索功能

### 💬 评论系统
- 用户评论发表
- 评论回复功能
- 嵌套评论显示

### 🎵 多媒体支持
- 视频播放（模拟播放器）
- 音频播放器（带进度条）
- 图片画廊和灯箱查看

### 🔍 搜索功能
- 实时搜索建议
- 全文搜索
- 搜索结果高亮显示
- 搜索历史

### 📱 响应式设计
- 移动端适配
- 桌面端优化
- 跨浏览器兼容

## 技术栈

- **HTML5** - 语义化标记
- **CSS3** - 现代化样式，Grid和Flexbox布局
- **JavaScript ES6+** - 模块化编程
- **本地存储** - 数据持久化

## 快速开始

### 运行本地服务器

由于浏览器的安全策略，需要通过HTTP服务器运行：

```bash
# 使用Python
python3 -m http.server 8080

# 使用Node.js (如果安装了http-server)
npx http-server

# 使用PHP
php -S localhost:8080
```

然后访问 `http://localhost:8080`

## 主要功能说明

### 1. 用户认证
- 点击右上角"登录"或"注册"按钮
- 支持表单验证和错误处理
- 登录状态持久化存储

### 2. 文章浏览
- 默认显示所有文章
- 使用分类筛选器筛选特定类型文章
- 点击文章卡片查看详细内容

### 3. 搜索功能
- 点击搜索图标打开搜索框
- 支持实时搜索建议
- 回车键或点击搜索按钮执行搜索

### 4. 评论功能
- 需要登录后才能评论
- 支持回复已有评论
- 评论支持嵌套显示

### 5. 多媒体
- 视频、音频、图片标签切换
- 点击视频卡片播放（模拟）
- 音频播放器支持播放控制
- 图片支持点击放大查看

## 设计特色

### 视觉设计
- **字体**: Playfair Display (标题) + Crimson Text (正文)
- **色彩**: 蓝灰色系，专业可信
- **布局**: 最大宽度720px，适合阅读
- **动画**: 流畅的过渡效果

### 用户体验
- **无障碍**: 键盘导航支持
- **性能**: 懒加载和性能优化
- **响应式**: 适配各种屏幕尺寸
- **错误处理**: 完善的错误提示机制
